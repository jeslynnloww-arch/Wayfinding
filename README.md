# Moss & Mug Wayfinding

A responsive café wayfinding experience built with plain HTML, CSS, and JavaScript.

## Features

- Illustrated café floor plan with selectable destinations
- Animated route overlay and turn-by-turn directions
- Step-free routing option
- Map zoom controls and responsive layout
- Help button with a friendly in-app message

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
